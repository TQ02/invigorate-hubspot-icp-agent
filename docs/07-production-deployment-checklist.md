# Production Deployment Checklist

V1 is not approved for production until every item is complete.

- [ ] Correct production portal independently verified.
- [ ] Subscription, AI settings, credits and run limits approved.
- [ ] Property names checked for production equivalents.
- [ ] Agent tools contain no direct CRM write action.
- [ ] Agent outputs and sources reviewed.
- [ ] Workflow enrollment excludes existing records on activation.
- [ ] Failure, none-met and low-confidence paths tested.
- [ ] Single-record test passed.
- [ ] Five-company regression passed.
- [ ] Rerun safety passed.
- [ ] No non-test records changed during validation.
- [ ] Monitoring and recovery owners assigned.
- [ ] Documentation and versions aligned.
- [ ] Security review completed.
- [ ] Final human approval recorded.
