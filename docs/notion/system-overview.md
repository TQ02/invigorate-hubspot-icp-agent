# System Overview

Owner: Thomas Quinn
Versions: Agent 1.0 · ICP 1.0 · Signal 1.0 · Workflow 1.0
Last reviewed: 2026-07-29
Canonical source: https://github.com/TQ02/invigorate-hubspot-icp-agent

The system researches a company with a read-only HubSpot agent using the explicitly attached `Invigorate OS — ICP & Signal Rules V1` knowledge vault, returns six structured fit, signal and confidence outputs, and lets a deterministic company workflow assign Prioritise, Monitor, Review, or Exclude.

The AI interprets evidence. HubSpot controls CRM writes and the operational decision.

GitHub is canonical, but its rule files are not automatically available to the agent. The approved Markdown files must be downloaded, uploaded to the named vault, attached and verified. Workflow Test is structural simulation only; runtime evidence requires a real restricted Case 1 enrollment.
