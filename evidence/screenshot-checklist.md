# Screenshot Checklist

Screenshots are optional working evidence and must not be committed until sanitized.

Before publication verify that each image contains:

- only the demo portal;
- no portal ID unless necessary and approved;
- only clearly labelled `[TEST]` records;
- no contact details, tokens, browser codes, private URLs, account menus or notifications;
- no unrelated customer or CRM data;
- the minimum crop needed to prove the result.

Evidence targets:

- portal name confirmation;
- agent instructions and allowed tools;
- knowledge vault name, both approved Markdown filenames, attached-agent state, and rules version;
- structured outputs;
- inactive workflow simulation, clearly labelled as simulation with no executed actions;
- activation review showing no-existing-record enrollment selected and the sole enrollment route;
- all five test companies at requested = No before activation;
- Case 1 requested transition from No to Yes;
- property mappings;
- deterministic branches;
- agent run sources and outputs;
- workflow history and selected branch;
- real property writes, completion date, and request reset from the Case 1 runtime enrollment;
- failure recovery;
- request reset and rerun;
- five-case result summary;
- agent credit estimate and run limit.
